terminal multiplexer
---
- Fleet View
  - persistent "server panes" detatchable terminal sessions
  - "client panes" which bind/render server panes
  - multiple persistent workspaces (arrangements of client panes)
  Ghese features culminate in a workflow reminiscent of claude fleet (agents) view - enabling hiding and recovering old terminal sessions. Effectively extending the claude agents view to other harnesses.
- Cli (+ claude skill) for controlling all pane interactions such as creation, sending messages, reading content
